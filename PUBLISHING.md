# Publishing Neural Green with the official VS Code packaging tool

This folder is a source project for `@vscode/vsce`. Do not upload a hand-built VSIX.

## 1. Install Node.js
Install a current Node.js LTS release from https://nodejs.org/ if `node` and `npm` are not already available.

## 2. Open a terminal in this folder
Run:

```powershell
node --version
npm --version
npm install --global @vscode/vsce
```

## 3. Validate and package
Run:

```powershell
vsce ls
vsce package
```

The command should generate `neural-green-1.0.3.vsix`. Install and test it in VS Code before publishing:

```powershell
code --install-extension .\neural-green-1.0.3.vsix
```

Then in VS Code, select **Preferences: Color Theme** and choose **Neural Green**.

## 4. Publish
Only after the publisher ID `Neuralcube` exists in the Visual Studio Marketplace portal and the VSIX installs successfully:

```powershell
vsce login Neuralcube
vsce publish
```

Follow the supported authentication prompts. Never paste your token into chat, source files, or screenshots.

## Important
The `.vsix` file generated by `vsce package` is the one to upload. Do not use a VSIX assembled manually by zipping files or editing `extension.vsixmanifest`.
