# Neural Green

**A Matrix-inspired green-on-black theme for focused coding.**

Neural Green brings the atmosphere of a digital-green terminal to Visual Studio Code, while keeping syntax colours distinct enough for everyday development.

## Features

- Near-black editor with deep green workbench panels
- Phosphor-green keywords, functions, cursor, and focus states
- Mint-green strings, teal types, lime numbers, and soft green variables
- Muted comments and line numbers to reduce visual noise
- Coordinated sidebar, tabs, terminal, Git decorations, diffs, and diagnostics
- Semantic highlighting enabled for compatible language extensions

## Colour palette

| Role | Colour |
| --- | --- |
| Editor background | `#030805` |
| Phosphor green | `#39FF88` |
| Mint | `#A2FFC2` |
| Teal | `#5EEAD4` |
| Lime | `#B7F36B` |
| Main text | `#C6F7D4` |

## Install

1. Open **Extensions** in VS Code (`Ctrl+Shift+X`).
2. Search for **Neural Green**.
3. Select **Install**.
4. Open **Preferences: Color Theme** and choose **Neural Green**.

## Recommended settings

For a clean Matrix-inspired workspace, try the theme with the default editor font you already find comfortable. No extra font or extension is required.
